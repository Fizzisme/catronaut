# Bản tiếng Việt — chỉ dành cho người đọc

Thư mục này chứa bản dịch tiếng Việt của tài liệu dự án, để team đọc nhanh hơn.

- **Bản chuẩn là tiếng Anh.** Khi hai bản khác nhau thì theo bản tiếng Anh; bản tiếng Việt có thể
  cập nhật chậm hơn.
- **Agent không đọc thư mục này.** Agent (Claude Code, Catronaut, …) chỉ đọc bản tiếng Anh.
- Mỗi file ở đây tương ứng 1:1 với một file tiếng Anh:

| Bản tiếng Việt | Bản chuẩn (tiếng Anh) |
|---|---|
| [ROADMAP.md](ROADMAP.md) | [ROADMAP.md](../../ROADMAP.md) |
| [book-guide/](book-guide/README.md) | [docs/book-guide/](../book-guide/README.md) |

Khi sửa một file tiếng Anh, cập nhật luôn bản tiếng Việt tương ứng, hoặc ghi rõ ở đầu file tiếng
Việt rằng bản dịch đang cũ.
