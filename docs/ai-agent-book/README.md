## How this was converted

- Generated by a one-off PyMuPDF script, not hand-typed. Text, headings, bold/italic, inline code,
  code blocks (indentation reconstructed), footnotes (`[^n]`) and tables were rebuilt from the PDF's
  layout.
- **Diagrams are PNG crops** in [`images/`](images/), named by their caption number
  (`fig-2-6.png` = *Hình 2-6*). Uncaptioned ones are named by page (`fig-p63-1.png`). The text
  inside a diagram is only in the image, not in the Markdown.
- **When something looks wrong, the PDF is authoritative.** Known soft spots of an automated
  conversion: a table split across two pages becomes two tables; list nesting is flattened to one
  level; a few cross-line spacing quirks from the source typesetting remain.
- Pages 1–8 (cover and the PDF's own table of contents) are replaced by the index below.
